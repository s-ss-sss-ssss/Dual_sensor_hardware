## 1. 快速查阅

AK09973D 是带可编程磁开关功能的三轴 Hall 磁传感器，内部包含 ADC、时钟、信号处理、寄存器和自检磁源。既可输出三轴磁场，也可通过阈值产生开关事件。

| 项目 | 速查值 |
| --- | --- |
| 工作电压 | **1.65～1.95 V，典型 1.8 V** |
| 工作温度 | -30～+85 °C |
| 输出 | X/Y/Z 各 16 位有符号补码 |
| 高灵敏度 `SMR=0` | 典型 1.1 μT/LSB，三轴约 ±36.04 mT |
| 宽量程 `SMR=1` | 典型 3.1 μT/LSB；X/Y 约 ±34.91 mT，Z 约 ±101.57 mT |
| I2C 7 位地址 | `0x10` 或 `0x11`，通过 IF1/IF2 接法选择 |
| I2C 速率 | 标准模式 ≤100 kHz；快速模式 ≤400 kHz；快速增强模式 ≤1 MHz |
| 身份读取 | `0x00` 读 4 字节：`48 C1 RSV_H RSV_L` |
| 状态读取 | `0x10` 读 1 字节 |
| 三轴读取 | **`0x17` 读 7 字节：`ST Z_H Z_L Y_H Y_L X_H X_L`** |
| 模式控制 | `0x21`，`CNTL2` |
| 软件复位 | 向 `0x30` 写 `0x01` |
| 数据就绪 | `ST & 0x01` |
| 磁场溢出 | `ST & 0x20` |
| 数据覆盖/丢样 | `ST & 0x40` |
| 默认复位状态 | Power-down；`CNTL1=0`、`CNTL2=0`、`ST=0x80` |

**三个关键区别：**宽量程主要扩大 Z 轴量程；1000/2000 Hz 仅在低功耗驱动下生效；芯片寄存器地址代表变长数据块，不是普通的逐字节地址布局。

来源：原文 pp.1、23～35。

## 2. 供电、引脚与外部电路

### 2.1 引脚和地址选择

| 焊球 | `0x10` 接法（Connection 1） | `0x11` 接法（Connection 2） |
| --- | --- | --- |
| A1 | VDD | VDD |
| A2 | VSS/GND | VSS/GND |
| A3 | SCL | SCL |
| B1 / IF1 | OD-INT | SDA |
| B3 / IF2 | SDA | OD-INT |

- SCL 和 SDA 输入具有施密特触发特性；SDA 输出为开漏。
- OD-INT 为**低有效开漏中断输出**；使用时需要上拉。
- **不使用 OD-INT 时，手册要求将对应引脚接 VSS。**
- 地址通过接线切换，芯片没有独立地址选择引脚。

### 2.2 工作条件和绝对最大额定值

| 参数 | 正常工作条件 | 绝对最大额定值 |
| --- | --- | --- |
| VDD | 1.65～1.95 V | -0.3～+2.5 V |
| 输入电压 | 推荐表给出 1.1 V～VDD | -0.3～VDD+0.3 V |
| 温度 | -30～+85 °C | 存储 -40～+125 °C |
| 输入电流 | 见 DC 特性 | -10～+10 mA |

绝对最大值是器件承受边界，不是允许长期运行的设计点。**VDD 不可直接使用 3.3 V；SCL/SDA 也不可直接上拉到 3.3 V。** MCU 一侧若使用 3.3 V，应根据实际电路采用适配的电平转换。

主要 DC 特性：SCL/SDA 输入高电平下限 1.00 V，输入低电平上限 0.42 V；开漏输出在 `IOL≤20 mA` 条件下 `VOL≤0.33 V`。这些条件不代表推荐使用 20 mA 上拉电流。

### 2.3 推荐外围元件

原文 pp.38～39 的示例电路采用：

- VDD 对地 **0.1 μF** 去耦。
- SCL/SDA 各 **3.3 kΩ** 上拉。
- OD-INT **20 kΩ** 上拉。
- 接口上拉电源可与 1.8 V VDD 相同；手册另提供 **1.2 V 接口电源**示例，芯片 VDD 仍为 1.65～1.95 V。

上述阻值属于示例。实际选择应结合总线电容、速率及电平转换器；快速增强模式要求上升/下降时间均不超过 120 ns。

### 2.4 上电与掉电时序

| 符号 | 含义 | 数值 |
| --- | --- | --- |
| PSUP | VDD 从 0.2 V 上升到工作电压的时间 | 最大 50 ms |
| PORT | 上升过程完成后，POR 到 Power-down 的时间 | 最大 100 μs |
| SDV | 为重新触发 POR，掉电需低于的电压 | 0.2 V |
| PSINT | 电压低于 SDV 的保持时间 | 最小 100 μs |
| Twait | 设置模式前等待时间 | 最小 100 μs |

PSUP/PORT/SDV/PSINT 为设计参考值。上电完成自动复位并进入 Power-down；软件启动时应留出等待裕量。原文未在软件复位章节给出独立的复位完成时间保证，不应将项目中的毫秒延时写成芯片规格。

来源：原文 pp.5～10、38～39。

## 3. 量程、灵敏度、噪声与功耗

### 3.1 `SMR`：量程与灵敏度

以下灵敏度与量程对应 `Ta=25 °C`；量程和噪声在手册中标为设计参考值。

| 参数 | 高灵敏度 `SMR=0` | 宽量程 `SMR=1` |
| --- | --- | --- |
| 灵敏度 min/typ/max | 0.99 / **1.1** / 1.21 μT/LSB | 2.79 / **3.1** / 3.41 μT/LSB |
| X/Y 量程 min/typ/max | ±32.44 / ±36.04 / ±39.64 mT | ±31.42 / ±34.91 / ±38.40 mT |
| Z 量程 min/typ/max | ±32.44 / ±36.04 / ±39.64 mT | ±91.42 / ±101.57 / ±111.73 mT |
| X/Y 原始有效范围 | -32768～32767 | **-11264～11264** |
| Z 原始有效范围 | -32768～32767 | -32768～32767 |
| 初始偏置范围 | -500～+500 LSB | -177～+177 LSB |

初始偏置是出厂测试未主动施加磁场时的数据范围，不代表安装后的系统零偏。典型换算系数也不等同于每颗器件校准后的精确比例系数。

### 3.2 `SDR`：低噪声与低功耗驱动

| 参数 | 低噪声 `SDR=0` | 低功耗 `SDR=1` |
| --- | --- | --- |
| 单次测量时间 typ/max | 0.825 / 0.908 ms | 0.265 / 0.292 ms |
| 高灵敏度噪声，典型 | 5.5 μT RMS | 15.0 μT RMS |
| 宽量程噪声，典型 | 6.8 μT RMS | 18.0 μT RMS |
| 10 Hz 平均电流，典型 | 11 μA | 3.5 μA |
| 100 Hz 平均电流，典型 | 101 μA | 22 μA |
| 最大有效连续测量频率 | 500 Hz | 2000 Hz |

功耗典型条件：VDD=1.8 V、25 °C，不含电阻负载。Power-down 电流典型 1 μA、最大 3 μA；磁传感器驱动期间电流典型 1.4 mA、最大 2.2 mA；自检期间典型 5.6 mA。

**测量时间不等于连续输出周期。** 例如低噪声单次测量约 0.825 ms，但连续 500 Hz 的周期为 2 ms。

来源：原文 pp.1、6、9、13、23。

## 4. I2C 通信与字节组织

### 4.1 地址与基本事务

| 7 位地址 | 总线上写地址字节 | 总线上读地址字节 |
| --- | --- | --- |
| `0x10` | `0x20` | `0x21` |
| `0x11` | `0x22` | `0x23` |

STM32 HAL 的 `DevAddress` 参数应传入 `addr7 << 1`；寄存器地址为 8 位，使用 `I2C_MEMADD_SIZE_8BIT`。总线地址字节与寄存器地址可能数值相同，但含义完全不同。

```text
写：START → SLA+W → ACK → 寄存器地址 → ACK → 数据字节... → ACK → STOP
读：START → SLA+W → ACK → 寄存器地址 → ACK
    → repeated START → SLA+R → ACK → 数据字节...
    → 主机对最后一字节 NACK → STOP
```

每字节按 MSB-first 传输；多字节数值也采用**高字节在前**。

### 4.2 变长寄存器块

地址 `0x20` 的 CNTL1 占 2 字节，地址 `0x21` 的 CNTL2 占 1 字节。向 `0x20` 写 2 字节表示写完整 CNTL1，不表示写 CNTL1 和 CNTL2 各一字节。

配置区 `0x20～0x25` 支持自动递增：依次完成各地址对应的数据块后进入下一地址，末尾从 `0x25` 回到 `0x20`。工程上建议按地址分别读写完整块，避免跨块长度错误。测量区 `0x11～0x1F` 则通过地址选择返回哪些轴及多少字节，不应按普通线性寄存器猜测。

芯片支持 current-address read 和 random-address read。工程上优先使用显式指定地址的 random read，避免依赖上一笔事务留下的内部地址计数器。

### 4.3 快速增强模式时序

| 项目 | 限值 |
| --- | --- |
| fSCL | ≤1000 kHz |
| SCL 高/低电平时间 | ≥0.26 / ≥0.5 μs |
| SDA/SCL 上升和下降时间 | 各 ≤120 ns |
| START 保持/建立时间 | 各 ≥0.26 μs |
| 数据保持/建立时间 | ≥0 / ≥50 ns |
| STOP 建立时间 | ≥0.26 μs |
| 总线空闲时间 | ≥0.5 μs |
| 噪声抑制脉宽 tSP | ≤50 ns |

来源：原文 pp.10、24～29。HAL 使用方式为本项目接口说明。

## 6. 状态与控制寄存器

### 6.1 身份 WIA：`0x00`

4 字节中的前两字节固定为 `0x48 0xC1`：公司 ID 为 `0x48`，设备 ID 为 `0xC1`，合起来 `WIA=0x48C1`。后两字节为 AKM 保留内容，不用来判断型号。

### 6.2 状态 ST：`0x10` 或测量块首字节

| 位 | 掩码 | 名称 | 含义 |
| --- | --- | --- | --- |
| 7 | `0x80` | 固定值 | 恒为 1 |
| 6 | `0x40` | DOR | 连续测量中发生数据覆盖/跳过 |
| 5 | `0x20` | ERR | 至少一轴磁传感器溢出 |
| 4 | `0x10` | SWV | 向量开关状态 |
| 3 | `0x08` | SWZ | Z 开关状态 |
| 2 | `0x04` | SWY | Y 开关状态 |
| 1 | `0x02` | SWX | X 开关状态 |
| 0 | `0x01` | DRDY | 测量数据就绪 |

- 新测量写入数据寄存器时 `DRDY=1`。
- **只读 ST 不清除 DRDY。** 完整读出任一测量数据寄存器，或访问设置区 `0x20～0x25`，会清除 DRDY。
- 数据读取开始后，芯片保护正在读取的数据，直到完整读完，避免同一事务中混入不同采样。
- 未读取上一组数据就完成下一次测量时可能发生 DOR；它不是磁场超量程。DOR 会在完成读取及后续测量等条件下更新/清除，原文 pp.16、31 的表述不完全一致，不能用它累计精确丢帧数。
- ERR 时输出相应轴的饱和值；磁场回到范围内后，后续测量会更新 ERR 和数据。

典型状态：复位后 `0x80`；数据就绪且无其他事件时 `0x81`。不要用 `ST==0x01` 判断就绪。

### 6.3 CNTL1：`0x20`，2 字节

| 位 | 名称 | 作用 |
| --- | --- | --- |
| 15:14 | 固定/保留 | 写 0 |
| 13 | RSV | **必须写 0** |
| 12 | 固定/保留 | 写 0 |
| 11:8 | POLV/POLZ/POLY/POLX | 向量/Z/Y/X 开关中断极性 |
| 7:6 | 固定/保留 | 写 0 |
| 5 | ERREN | 1：允许溢出事件输出 |
| 4:1 | SWVEN/SWZEN/SWYEN/SWXEN | 1：允许对应开关事件输出 |
| 0 | DRDYEN | 1：允许数据就绪事件输出 |

写入顺序：`CNTL1_H` 在前，`CNTL1_L` 在后。例如仅启用 DRDY 输出写 `[0x00, 0x01]`；全部关闭写 `[0x00, 0x00]`。

### 6.4 CNTL2：`0x21`，1 字节

```text
bit7     bit6    bit5    bit4..0
STEST    SMR     SDR     MODE

CNTL2 = (STEST << 7) | (SMR << 6) | (SDR << 5) | MODE
```

| MODE | 模式 | 频率 / 行为 |
| --- | --- | --- |
| `0x00` | Power-down | 停止测量，寄存器可访问，配置保留 |
| `0x01` | 单次测量 | 完成后自动回 Power-down，MODE 清零 |
| `0x02` | 连续模式 1 | 5 Hz |
| `0x04` | 连续模式 2 | 10 Hz |
| `0x06` | 连续模式 3 | 20 Hz |
| `0x08` | 连续模式 4 | 50 Hz |
| `0x0A` | 连续模式 5 | 100 Hz |
| `0x0C` | 连续模式 6 | 500 Hz |
| `0x0E` | 连续模式 7 | SDR=1 时 1000 Hz；SDR=0 时实际 500 Hz |
| `0x10` | 连续模式 8 | SDR=1 时 2000 Hz；SDR=0 时实际 500 Hz |
| 其他 MODE 值 | Power-down | 建议明确写 `0x00` |

SMR：0=高灵敏度，1=宽量程。SDR：0=低噪声，1=低功耗。STEST：1=启用自检，**仅配合单次测量有效**。

| CNTL2 示例 | 配置 |
| --- | --- |
| `0x04` | 高灵敏度、低噪声、10 Hz |
| `0x0C` | 高灵敏度、低噪声、500 Hz |
| `0x2E` | 高灵敏度、低功耗、1000 Hz |
| `0x30` | 高灵敏度、低功耗、2000 Hz |
| `0x70` | 宽量程、低功耗、2000 Hz |
| `0x81` | 自检单次测量 |

### 6.5 SRST：`0x30`

bit0=1 触发软件复位，其他位写 0。复位后寄存器初始化、进入 Power-down，SRST 自动清零。软件复位会清掉量程、驱动、阈值和中断配置，需要重新配置。

来源：原文 pp.13～16、19、31～37。

## 7. 初始化、采样与模式切换

### 7.1 推荐初始化流程

1. 确认供电与接口电平，完成上电等待；使用 TCA9548A 时先选中目标通道。
2. 向 `0x30` 写 `0x01` 软复位，并留出完成裕量。
3. 从 `0x00` 读 4 字节，确认前两字节为 `48 C1`。
4. 在 Power-down 下写 CNTL1 和需要的阈值，保留位写 0。
5. 最后向 `0x21` 写所需 CNTL2，开始单次或连续测量。
6. 轮询 `0x10` 的 DRDY，或等待 OD-INT。
7. 从 `0x17` 完整读 7 字节，先检查状态，再解析、换算三轴值。

此顺序是工程建议。首帧等待应按输出周期设置：例如 5 Hz 周期为 200 ms，不应复用仅覆盖较高频率的短超时。

### 7.2 正常读数流程

```text
等待 DRDY=1
    ↓
从 0x17 连续读 7 字节
    ↓
检查本次返回的 ST：DRDY / ERR / DOR
    ↓
将 Z、Y、X 大端补码转为有符号数
    ↓
按本次量程换算，保存状态和时间戳
```

读取期间芯片保护数据。建议一次读取完整三轴块，减少跨事务时三轴不同步的可能性。一次读完后保护解除，DRDY/DOR 按数据读取完成规则更新。

若在测量正在进行时开始读，读到的是此前存储的数据。因此 I2C 成功不代表读到了新样本；应保留并检查返回 ST 的 DRDY。

### 7.3 切换或停止测量

- 手册允许通过直接写 MODE 切换连续模式；停止连续测量可写 Power-down。
- 工程建议：修改阈值、量程或驱动时先停止测量，再配置，最后恢复测量。
- **访问 `0x20～0x25` 设置区会影响数据更新、开关状态和 DRDY。** 不要把配置寄存器回读放进正常高频采样循环；配置完成后重新等待新数据。
- 单次测量需每次重新写入单次 MODE；读数据本身不触发下一次单测。

来源：原文 pp.13～17、21～22。

## 8. 原始数据解析和物理量换算

### 8.1 解析 `0x17` 的三轴数据

以下代码仅展示收到 7 字节后的解析，不含通信及有效性判断：

```c
/* buf: ST, Z_H, Z_L, Y_H, Y_L, X_H, X_L */
uint8_t st = buf[0];
int16_t hz = (int16_t)(((uint16_t)buf[1] << 8) | buf[2]);
int16_t hy = (int16_t)(((uint16_t)buf[3] << 8) | buf[4]);
int16_t hx = (int16_t)(((uint16_t)buf[5] << 8) | buf[6]);

bool ready    = (st & 0x01u) != 0;
bool overflow = (st & 0x20u) != 0;
bool overrun  = (st & 0x40u) != 0;

float sensitivity_uT = smr ? 3.1f : 1.1f;
float bx_uT = hx * sensitivity_uT;
float by_uT = hy * sensitivity_uT;
float bz_uT = hz * sensitivity_uT;
```

使用 `bool` 时包含 `<stdbool.h>`，使用整数类型时包含 `<stdint.h>`。`smr` 应对应该样本测量时的量程配置。

通用补码解析：先组合无符号值 `u`，若 `u≥32768`，有符号值为 `u-65536`。`0xFFFF=-1`，`0x8000=-32768`。

### 8.2 单位换算

```text
高灵敏度：B[μT] ≈ raw × 1.1
宽量程：  B[μT] ≈ raw × 3.1
B[mT] = B[μT] / 1000
B[T]  = B[μT] × 10^-6
```

例如高灵敏度下 raw=1000 对应约 1100 μT=1.1 mT；raw=-1000 对应约 -1.1 mT。用于精确磁场估计时，还需处理器件灵敏度误差、零偏和安装方向；这些校准属于系统设计工作。

### 8.3 饱和与有效性

| 设置与轴 | 负/正饱和原始值 | 对应典型磁场 |
| --- | --- | --- |
| 高灵敏度，各轴 | -32768 / 32767 | -36.0448 / +36.0437 mT |
| 宽量程，X/Y | -11264 / +11264 | -34.9184 / +34.9184 mT |
| 宽量程，Z | -32768 / 32767 | -101.5808 / +101.5777 mT |

同一个边界值可对应未溢出的边界磁场，也可对应超量程后的钳位输出，必须结合 ERR 判断。ERR 是公共状态位，不直接指出哪一轴溢出。

工程建议：DRDY=0 不作为新样本；ERR=1 标记饱和并避免直接用于精确拟合；DOR=1 标记发生过跳样，但不把它当丢帧计数器。

### 8.4 HV：三轴平方和

从 `0x18` 读 5 字节，首字节为 ST，后 4 字节组成无符号 32 位 HV：

```text
HV = HX² + HY² + HZ²
|B|[μT] ≈ sqrt(HV) × sensitivity[μT/LSB]
```

HV 是**平方和**，不是已开平方的磁场模长，也不是物理单位下的平方和。按三轴最大绝对值推导，最大平方和为 3×32768²=3221225472，超过 `int32_t` 正范围；主机自行计算时宜使用 64 位中间量。

```c
uint64_t hv = (uint64_t)((int64_t)hx * hx)
            + (uint64_t)((int64_t)hy * hy)
            + (uint64_t)((int64_t)hz * hz);
```

原文把本节标题写为 `HV[23:0]`，但寄存器表、4 字节数据及公式均给出 `HV[31:0]`，应按 32 位读取。

来源：原文 pp.29、32～34；换算公式和主机溢出分析为据此推导。

## 9. 可编程磁开关与中断

### 9.1 阈值与滞回

每个轴和向量通道各有工作阈值 BOP 与返回阈值 BRP。以 X 为例：

| 条件 | SWX |
| --- | --- |
| `BOPX≤BRPX` | 开关功能禁用，结果不应使用 |
| `HX>BOPX` 且 `BOPX>BRPX` | 1 |
| `HX<BRPX` 且 `BOPX>BRPX` | 0 |
| `BRPX≤HX≤BOPX` 且 `BOPX>BRPX` | 保持前一次状态 |

边界使用**严格大于/小于**；相等时属于保持区。Y、Z 和向量通道同样有滞回关系。

轴阈值采用 16 位有符号补码，与轴测量数据单位一致。例如高灵敏度下设置 X 工作阈值 1.1 mT、返回阈值 0.55 mT：BOPX=1000，BRPX=500，向 `0x22` 写 `[0x03,0xE8,0x01,0xF4]`，并按需要配置 CNTL1 的 SWXEN/POLX。

设置区块对应：`0x22`=X，`0x23`=Y，`0x24`=Z，`0x25`=向量，各块都是 BOP 高/低字节在前、BRP 高/低字节在后。

**向量阈值限制：**BOPV/BRPV 为 16 位字段，而 HV 为 32 位平方和；p.37 又用磁场模长单位列出向量阈值。该版本没有清楚写出二者比较时的计算式，且数值表存在错误。不要直接把平方和截断写入向量阈值，也不要擅自将向量阈值解释为轴的有符号阈值；实现前应向厂家核实，或用已知磁场实测验证。

### 9.2 OD-INT 事件与极性

| 事件 | 启用位 | 行为 |
| --- | --- | --- |
| 数据就绪 | DRDYEN | 测量完成时拉低 |
| 磁场溢出 | ERREN | ERR 事件存在时拉低 |
| X/Y/Z/向量开关 | 对应 SWEN | 根据开关状态及对应 POL 决定是否拉低 |

POL=0：超过 BOP 时开关中断有效、OD-INT 拉低；低于 BRP 后释放。POL=1：对应开关输出逻辑相反。POL 控制开关事件极性，不将开漏输出变成主动驱动高电平；“H”由外部上拉得到。

多个事件同时启用时，应读取 ST 判断实际来源。

### 9.3 中断释放与状态清除不是同一件事

- DRDY 中断在读取 `0x10～0x1F` 地址或写 `0x20～0x25` 地址时释放；访问地址期间 OD-INT 为 H。
- **读 ST 可以释放 DRDY 引脚中断，但 ST.DRDY 仍保持 1，直到完成测量数据读取等规定操作。**
- 开关/溢出中断根据后续测量的事件状态更新；写设置区也会使输出释放。

来源：原文 pp.17～22、34、36～37。

## 10. 自检

自检使用内部磁源检查传感器。启用条件为 `STEST=1` 且 `MODE=0x01`，可直接向 CNTL2 写 `0x81`。

1. 保存需要恢复的正常配置，进入 Power-down。
2. 向 `0x21` 写 `0x81`。
3. 等待 DRDY=1，并设置软件超时。
4. 从 `0x17` 完整读 7 字节，按正常规则解析。
5. 检查原始值是否同时满足下表。
6. 显式写回正常 CNTL2，清除 STEST 并恢复采样。

| 轴 | 合格原始值范围，含边界 |
| --- | --- |
| HX | -120～+120 |
| HY | -120～+120 |
| HZ | +60～+400 |

自检时 SDR 和 SMR 设置无效，测量强制使用低噪声和高灵敏度。结束后自动回 Power-down；手册明确 MODE 清零，没有明确保证 STEST 自动清零，因此恢复工作时应显式写正常配置。

上述判据单位为原始 LSB，不是 μT。工程验证宜避免强外磁场干扰，并记录通信状态与测量状态，区分通信失败和数值不合格。

来源：原文 pp.13～14、18、35。

```text
AK,bus,tca_mask,hx,hy,hz,drdy,err,dor
```

### 12.1 阵列带宽估算

以下为通信推导，不是手册给出的系统性能保证：

```text
随机读 7 字节：写从地址 + 寄存器地址 + 读从地址 + 7 字节
共 10 个 9-clock 单元 ≈ 90 SCL clocks
400 kHz 下理想占线时间 ≈ 225 μs

一次 TCA 选通：地址 + 掩码 ≈ 18 clocks ≈ 45 μs
选通并读取一个器件 ≈ 270 μs
每总线 6 个器件 ≈ 1.62 ms / 轮
若两条总线按阻塞方式串行采集 12 个器件 ≈ 3.24 ms / 轮
```

该估算未计 START/STOP、软件处理、USB、失败重试和其他传感器访问。500 Hz 传感器周期为 2 ms，因此 MCU 完整轮询频率可能低于每颗传感器的内部测量频率，DOR 可能出现。TCA 切换只改变通信通路，不同步各传感器采样；读数时间戳也不等于芯片测量完成时刻。

### 12.2 多通道接入建议

- 同一总线上多个相同 `0x10` 地址分支，应一次仅选通一个目标通道，避免地址冲突。
- 软件复位作用于 AK09973D；板上 I2C1_RESET/I2C2_RESET 是系统复位线路，不能仅凭名称将其当成 AK09973D 的复位引脚，因为该器件本身没有专用复位脚。
- 更改频率时同步检查 SDR、读取吞吐、DRDY 等待和主机单位换算。

## 13. 故障排查

| 现象 | 优先检查 |
| --- | --- |
| 设备不 ACK | 1.8 V 供电、IF1/IF2 接法、7 位地址、HAL 左移地址、TCA 选通、电平与上拉 |
| WIA 不为 `48 C1` | 是否选错器件、是否按 `0x00` 读取完整块、通信是否成功 |
| ST 常为 `0x80` | 是否仍在 Power-down；CNTL2 是否写入有效 MODE；是否频繁访问设置区 |
| DRDY 已读但中断释放 | 正常机制：ST 读取释放中断，不必然清除 DRDY |
| 数据重复 | 返回 ST 是否 DRDY=0；主机是否读取过快；是否在下一次测量完成前读到旧数据 |
| DOR 频繁 | 读取周期慢于测量周期；TCA、USB、其他传感器或错误重试占用时间 |
| ERR=1 或轴数据钳位 | 外磁场是否超量程；尤其宽量程 X/Y 仍仅约 ±34.9 mT |
| 设置 1000/2000 Hz 却只有 500 Hz | SDR 是否为 0；应切换低功耗 SDR=1 |
| 磁场数值差约 2.82 倍 | 实际 SMR 与主机使用的 1.1/3.1 μT/LSB 系数是否一致 |
| X/Z 混乱或负数异常 | `0x17` 返回 Z/Y/X，且高字节在前、16 位补码 |
| 5 Hz 初始化超时 | 首帧等待是否短于 200 ms 周期 |
| 自检失败 | 是否写 `STEST=1 + MODE=1`；是否使用原始值比较；通信及强外磁场干扰 |

## 14. 原文疑点与页码索引

### 14.1 本版手册存在的文字/表格不一致

1. **HV 位宽：**目录和章节标题称 `HV[23:0]`，pp.29～34 给出的读取长度、字段和公式实际为 32 位。本文按 `HV[31:0]` 整理。
2. **向量阈值：**p.37 表 12.10 把 `0xFFFF` 十进制写为 65536，并使用 “Two’s complement” 列名；16 位 `0xFFFF` 作为无符号值应为 65535，作为有符号补码则为 -1。本文不沿用该错误，也不补造未明确给出的向量比较算法。
3. **DOR 清除：**p.16 和 p.31 对后续测量清除时机的表述有差别；正常完整读取结束会更新/清除 DRDY/DOR，但 DOR 不是永久累计状态。需要精确诊断时应结合总线抓取实测。
4. **位名：**表中出现 `SELFT/STEST`、`ERROREN/ERREN` 两种写法，位位置相同；本文统一采用详细章节的 STEST/ERREN。
5. **测试寄存器权限：**总表与详细表对 TEST1/TEST2 权限描述不一致，但都要求禁止访问，本文遵循这一要求。
